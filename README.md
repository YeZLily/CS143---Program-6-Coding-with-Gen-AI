# CS143---Program-6-Coding-with-Gen-AI

Prompt:

Write a Java program using OOP for a coffee shop rewards system. I want the program to have customers, drinks, and orders. Customers should be able to buy drinks and reward points based on what they purchase. I want to use a HashMap to store customers by their customer ID, so the program can find a customer easily. Also I want to use an ArrayList to store the drink menu. The program should allow a customer to check their points and redeem points for a reward.


Reflection:

1. What did you learn in the process?
- I learned that using GenAI still requires my own thinking. I had to decide what I wanted the program to do, explain my ideas clearly, and check if the code matched my goal. I also learned that AI can help, but it does't always understand everything exactly the first time.

2. What were the benefits of working with GenAI?
- One benefit of working with GenAi was that it helped me create a first version of my code quickly. It also helped organize the program into different classes and make specific changes, like in this case adding new features to the coffee shop rewards system.
  
3. What were the drawbacks?
- One drawback was that sometimes AI didn't fully understand what I wanted. For example, I might ask for one specific change, but it could change other parts of the program too or give me something slightly different from what I expected.

4. Any other thoughts?
- In general, I think it's useful, but it s still required my own decisions and corrections. I couldn't just accept everything it generated without checking it and needed to guide the process, ask specific changes, and make sure it fits what I want.
